# Examples

| Directory | System | Calculator | Stages | Reference outputs |
|---|---|---|---|---|
| [`MgO_225`](MgO_225/README.md) | Rock-salt MgO (Fm-3m) | SevenNet-0 | 1–7, plus a QHA-only refit | Yes |

Each example directory holds an input structure, complete configuration files and, where
available, a `reference/` directory with the outputs of a developer run. Run an example from
inside its directory; `qhab` writes all outputs to the current directory.

Only the relaxed structures, logs and QHA tables of the reference run are shipped. The
displaced supercells, force sets, force constants and q-mesh data are regenerated by running
the example.

To try another potential, change only the `calculator` block of `config.yaml`, for example

```yaml
calculator:
    calc: 7net
    model: omni        # SevenNet-Omni
    modal: mpa         # PBE-level channel (MPtrj + sAlex)
```

or `model: nano-6.0` with `modal: false` for SevenNet-Nano with a 6.0 Å cutoff. See
[Supported Calculators](../README.md#supported-calculators) for the other backends.
